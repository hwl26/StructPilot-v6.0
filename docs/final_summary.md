### **问题2：桌宠未显示**

#### **✅ 已修复**

**根本原因：** 复杂的桌宠组件 JavaScript 通信失败，导致 DOM 中没有渲染桌宠元素

**解决方案：** 创建简化版桌宠 + 自动降级机制

**修改位置：**
- 新增文件：`ui/components/simple_desk_pet.py`
- 修改文件：`main.py`（添加降级逻辑）

**简化版桌宠特性：**
1. **纯CSS动画** — 无需复杂的 JavaScript
2. **5种桌宠类型** — 🐧企鹅 / 🐱猫 / 🐶狗 / 🤖机器人 / 🐰兔子
3. **5种心情动画**
   - `idle` — 漂浮动画（等待开始）
   - `happy` — 弹跳动画（庆祝）
   - `working` — 摇摆动画（工作中）
   - `done` — 庆祝动画（完成）
   - `error` — 抖动动画（出错）
4. **悬停效果** — 缩放 + 阴影 + 提示信息
5. **轻量高效** — 无通信开销，兼容性强

**自动降级机制：**
```python
try:
    # 优先尝试完整版桌宠（高级功能）
    pet_value = render_desk_pet(...)
except Exception:
    # 失败则自动降级为简化版
    render_simple_desk_pet(...)
```

**测试结果：**
- ✅ 右下角能看到桌宠（emoji形式）
- ✅ 悬停有放大动画
- ✅ 根据流程状态自动切换动画
