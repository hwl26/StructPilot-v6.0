#### **1. 论坛权限控制**
**位置：** `utils/forum_ui.py`

**增强内容：**

```python
def render_forum_tab():
    from utils.user_manager import get_current_user

    current_user = get_current_user()
    user_role = current_user.get("role", "guest") if current_user else "guest"

    # 访客提示
    if user_role == "guest":
        st.info("👁️ 访客模式：您可以浏览内容，登录后可参与讨论")

    # 提问按钮（访客不显示）
    if user_role in ["member", "admin"]:
        if st.button("➕ 提问"):
            st.session_state["forum_create_question"] = True
    else:
        st.caption("💡 登录后可提问")
```
